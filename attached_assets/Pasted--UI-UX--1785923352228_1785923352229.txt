Проведи комплексный аудит пользовательского интерфейса (UI) и пользовательского опыта (UX) моего десктопного приложения. Твоя задача — выступить как ведущий Product Designer уровня Apple, Microsoft, Adobe, Figma и Linear, специализирующийся на современных десктопных приложениях 2026 года. Не ограничивайся исправлением отдельных элементов. Предложи полноценный рефакторинг интерфейса с сохранением всей существующей функциональности, но с максимально современным внешним видом и улучшенным пользовательским опытом. Основные требования Проведи анализ: визуального стиля; композиции экранов; структуры интерфейса; расположения элементов; типографики; цветовой схемы; иконок; отступов; размеров элементов; логики навигации; поведения элементов; сценариев работы пользователя. Затем предложи конкретные изменения. Используй лучшие практики UI/UX 2026 года При проектировании ориентируйся на современные подходы: Fluent Design 3 Windows 11 Design Apple Human Interface Guidelines Material Design 4 Linear App Figma Desktop Notion Arc Browser Raycast Cursor Warp Obsidian JetBrains IDE Visual Studio Code Но не копируй их напрямую — используй их как источник лучших решений. Обязательно оцени Первое впечатление Насколько современно выглядит приложение? Что сразу выдает устаревший дизайн? Какие элементы выглядят перегруженными? Что отвлекает пользователя? Визуальная иерархия Проверь: контраст акценты размеры заголовков размеры кнопок интервалы расстояния группировку информации выравнивание плотность интерфейса 3. Компоновка Предложи более удачное расположение: панели инструментов меню навигации карточек таблиц блоков панели действий области просмотра боковой панели статус-бара панели поиска 4. Навигация Предложи: более логичную структуру уменьшение количества кликов быстрый доступ к важным функциям улучшение поиска улучшение фильтрации улучшение работы с горячими клавишами 5. UX Найди места, где пользователь: делает лишние действия долго ищет нужную функцию может ошибиться может потерять данные не понимает состояние программы не получает обратной связи Для каждого случая предложи решение. Современные UI-фишки Предложи, где можно использовать: Command Palette глобальный поиск Spotlight-поиск контекстные панели Smart Toolbar Floating Toolbar адаптивные панели Dock Panels Split View мастер-панели breadcrumbs skeleton loading shimmer loading drag & drop inline editing inline validation smart notifications toast-уведомления undo/redo history быстрые действия контекстные меню закрепляемые панели виртуализацию больших списков плавные анимации микроанимации Empty States Onboarding подсказки Progressive Disclosure адаптивные диалоги интеллектуальные настройки 7. Типографика Предложи: современные шрифты размеры интервалы высоту строк веса визуальную иерархию 8. Цветовая система Предложи: современную палитру Accent Color Secondary Colors Success Warning Error Info Surface Colors Elevation разделение цветов для светлой и темной темы 9. Компоненты Для каждого компонента оцени необходимость рефакторинга: кнопки поля ввода переключатели чекбоксы выпадающие списки вкладки карточки таблицы модальные окна уведомления тултипы индикаторы загрузки прогресс-бары меню контекстные меню панели инструментов статус-бары дерево элементов 10. Accessibility Проверь: контраст размеры кликабельных областей навигацию с клавиатуры работу Tab фокус масштабирование поддержку экранов высокой плотности (HiDPI) поддержку разных разрешений 11. Производительность интерфейса Предложи способы сделать интерфейс быстрее: уменьшение количества перерисовок виртуализация списков ленивую загрузку оптимизацию анимаций оптимизацию теней оптимизацию эффектов уменьшение визуального шума 12. Итоговый рефакторинг Составь полный план модернизации интерфейса: что оставить без изменений; что переработать полностью; что удалить; что добавить; что объединить; что упростить; что автоматизировать. Распредели предложения по приоритетам: Критично, Высокий приоритет, Средний приоритет, Низкий приоритет. Для каждого пункта объясни, почему это улучшит пользовательский опыт. Если анализируется исходный код проекта Изучи весь проект целиком: структуру каталогов; все окна; все пользовательские сценарии; используемые UI-компоненты; стили; ресурсы; изображения; SVG; иконки; шрифты; темы оформления; систему цветов; отступы; дизайн-систему. Не ограничивайся одним файлом. Анализируй взаимосвязи между всеми экранами приложения и предлагай единый, целостный дизайн. Если обнаружишь повторяющиеся компоненты, предложи вынести их в единую библиотеку (Design System) с использованием дизайн-токенов (цвета, размеры, отступы, радиусы, типографика, тени, анимации). Не меняй бизнес-логику приложения. Все предложения должны касаться исключительно улучшения UI, UX, структуры интерфейса и удобства использования. Каждый вывод сопровождай конкретным обоснованием с точки зрения современных принципов проектирования десктопных приложений 2026 года.
