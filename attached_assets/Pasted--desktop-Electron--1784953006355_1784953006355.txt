Создай современный desktop-интерфейс приложения "Фотоцентр ГермесГарант" для Electron.

Использовать только:

- HTML5
- CSS3
- Vanilla JavaScript
- Никаких React, Vue, Angular, Bootstrap, Tailwind, jQuery и других библиотек.

Интерфейс должен практически повторять приложенный макет по структуре, композиции, размерам панелей и общему стилю, но не копировать его пиксель в пиксель. Дизайн должен выглядеть как современное коммерческое desktop-приложение уровня Adobe Lightroom, Capture One, Figma Desktop или Affinity Photo.

========================
Требования
========================

Приложение работает в Electron.

Размер окна по умолчанию:

1600×950

Минимальный размер:

1280×800

Все панели должны растягиваться вместе с окном.

Использовать CSS Grid и Flexbox.

Никакого абсолютного позиционирования для построения основного интерфейса.

========================
Архитектура
========================

Создать структуру проекта:

renderer/

index.html

css/

variables.css

layout.css

components.css

app.css

js/

app.js

Не писать весь CSS в одном файле.

Разделить по назначению.

Каждая крупная панель должна иметь собственный класс:

.app-header

.app-sidebar

.app-gallery

.app-editor

.app-inspector

.app-footer

========================
Важно
========================

Не реализовывать обработку фотографий.

Не писать бизнес-логику.

Не использовать canvas API.

Не использовать сторонние библиотеки.

Сделать только профессиональный, полностью адаптивный интерфейс, максимально похожий по архитектуре на макет, готовый для последующего подключения функциональности.
